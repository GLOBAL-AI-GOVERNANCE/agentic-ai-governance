# Security Policy

## Supported material

This experimental repository contains specifications, schemas, fixtures, and conformance utilities. It does not contain a production evaluator, signing service, continuous-monitoring service, or production connector.

## Private reporting

Do not disclose suspected vulnerabilities in public issues. Use GitHub private vulnerability reporting:

`https://github.com/GLOBAL-AI-GOVERNANCE/agentic-ai-governance/security/advisories/new`

Include the affected version or commit, impact, reproduction steps, expected behavior, and proposed mitigation. Never include production private keys, credentials, regulated data, or third-party secrets.

## Scope boundary

A successful schema validation or conformance run does not establish operational security, factual truth of declarations, source-system correctness, legal compliance, or institutional authorization.
