# Security Policy

This repository does not operate an external security-report intake. Do not place secrets, credentials, personal data, sensitive operational information, or vulnerability material in public GitHub surfaces.

## Supported material

This experimental repository contains specifications, schemas, fixtures, and conformance utilities. It does not contain a production evaluator, signing service, continuous-monitoring service, or production connector.

Never place production private keys, credentials, regulated data, or third-party secrets in repository content.

## Scope boundary

A successful schema validation or conformance run does not establish operational security, factual truth of declarations, source-system correctness, legal compliance, or institutional authorization.
